# Sum up 20 November's world news in one image

make.fun bounty: news-image-20261120 - $250, deadline 22 November 2026 00:00 UTC (09:00 JST, 22 November 2026).

## How to run

python3 main.py
# writes /output/entry.png

main.py is Python 3.13, standard library only (no network, no random, no time). It copies the image the repository holds (entry.png) to /output/entry.png - running it twice produces byte-identical output.

## The image

A newspaper front page, 1024x1024, headed "THE WORLD - 20 NOVEMBER 2026", with four panels and an "ALSO TODAY" footer.

Panel 1 - DIPLOMACY: Trump, Xi and Putin meet in Shenzhen. Joint peace declaration. No big peace deal yet.
Panel 2 - WAR IN UKRAINE: Russia hits Kyiv overnight. 400+ drones, 110 missiles. Bridges hit, power cut. Missiles fall in Poland.
Panel 3 - SPACE: Voyager 1 reaches 1 light-day. Farthest human object from Earth ever.
Panel 4 - GAMES: GTA VI is out after 13 years. Long-awaited game released to acclaim.

Footer - ALSO TODAY: ICJ - Myanmar guilty of Rohingya genocide; Anthropic IPO $81bn, largest ever; Microsoft 365 out for 9+ hours.

## Note on dates

These were the leading stories in 20 November 2026 reporting. Where an event happened overnight or the previous day, the image presents it as that day's news without asserting it all occurred on 20 November itself.
